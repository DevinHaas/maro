# Issue tracker

Maro uses GitHub Issues in `DevinHaas/maro`. Use `gh issue view`, `gh issue list`, and
`gh issue create` to read and manage tickets. Implementation issues stay open
until the integration pull request is merged; include `Closes #N` references in
the pull request. The redesign parent is issue #1 and its source specification
is `docs/specs/spotify-style-application-redesign.md`.
